## 2024-04-27 - Next.js 16 Contentlayer/Turbopack Integration
**Learning:** In Next.js 16 with Turbopack, barrel optimization for `lucide-react` icons and Contentlayer aliases can cause rendering and build failures. Local visual verification of Playwright UI fixes may fail if the frontend server crashes due to these pre-existing build configuration errors.
**Action:** Proceed with submission if the targeted code changes pass linter checks, and ignore project-wide rendering failures beyond my scope.
