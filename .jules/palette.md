## 2024-05-08 - Added Async Loading State & Accessibility to AI Assistant
**Learning:** Found an interaction pattern where the AI Assistant lacked a loading state for an async simulated response, leaving the user with no visual feedback and vulnerable to spam-clicking the send button, which is particularly disorienting given the small chat UI. Additionally, icon-only buttons lacked essential `aria-label` attributes.
**Action:** Implemented a robust `isLoading` state coupled with an animated visual typing indicator. Added `disabled` attributes alongside `aria-disabled` for both the input field and submit button to prevent double-submissions, ensuring screen readers announce the state change. Addressed accessibility by attaching explicit `aria-label` and `aria-expanded` attributes to icon-only control buttons.
