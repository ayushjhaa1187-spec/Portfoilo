# Ayush Kumar Jha — Portfolio

The personal portfolio and technical laboratory of Ayush Kumar Jha, an AI Engineer and Full-Stack Architect from IIT Madras.

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion
- TypeScript

## Local Development

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
