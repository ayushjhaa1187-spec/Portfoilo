## 2024-05-10 - Optimizing Mongoose Read-Only Queries with .lean()
**Learning:** By default, Mongoose returns full Mongoose documents from queries, which includes overhead like internal state, change tracking, and instance methods (e.g., `.save()`). This instantiation is expensive for memory and CPU when simply fetching data to return as JSON in a REST API.
**Action:** Append `.lean()` to all read-only Mongoose queries (e.g., `.find().lean()`, `.findOne().lean()`) in Express routes. This instructs Mongoose to return plain JavaScript objects instead of Mongoose documents, making the query significantly faster (often 3-5x) and significantly reducing memory usage. This pattern should be applied by default for all `GET` endpoints fetching data from MongoDB unless Mongoose specific instance methods are explicitly required.
